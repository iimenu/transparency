# transparency

Correspondence and documentation relating to legal notices, accusations, and other complaints received by the operators of iistupid.com and github.com/iireborn.

## Contents

All original notices are preserved verbatim and unaltered. Responses are published as sent, with only the omission of Authorization sections. Nothing in this repository has been edited after the fact.

## Purpose

This repository exists to maintain a public record of all correspondence in this matter. It will be updated as events warrant.
